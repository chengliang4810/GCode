# Unresolved license and provenance items

The original texts included in this package are verified source documents.
The following items have not been resolved by inventing authors, substituting
generic license wording, or treating a successful package check as legal clearance.

1. **Newly authored replica source license.** The original Zeron MIT text covers
   the imported Zeron material; this task has not assigned a license or copyright
   holder to all newly authored Go code. The Shades of Purple adaptation retains
   its original additional MIT condition in the theme notices. The project owner
   still needs to record the intended project license for an external release.
2. **Provider brand marks.** The reference contains provider/product logos as
   source assets, but no separate, complete permission or trademark-policy record
   for each mark was found alongside them. Their inclusion is recorded as reference
   artwork; the Solar and Symbols licenses are not applied to those distinct marks.
3. **Native toolchain/runtime closure.** MyGo pins the Ghostty-VT binary hashes
   and source commit but supplies no complete per-binary third-party SBOM or build
   logs. The Ghostty root MIT, uucode/Unicode, Highway, actual simdutf 9.0.0 and Wuffs
   notices are included. The complete Zig compiler-runtime / target libc notice
   closure has not been established from those binary publication records.
4. **Thumbnail attribution detail.** The original `image-thumbnail.MIT` notice
   supplies MIT permission text without a named copyright holder. Its text is
   preserved exactly; no copyright name has been fabricated.

No actual license text is missing for the explicitly inventoried Go modules,
Geist, six math-font families, Symbols, CC BY 4.0, original Zeron/MyGo, or the
named renderer packages. A release file/hash check verifies packaging integrity;
it does not close the provenance items above or constitute a license audit opinion.
