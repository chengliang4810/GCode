# Original background raster reference

This small console exporter executes the unmodified raster, cover-sampling and
dither methods from `crates/ui/src/new_thread_background_effects.rs` at the
frozen source commit. A small `Pixels`/`Size` bridge replaces GPUI's geometry
types; the adapter converts the original BGRA upload buffer back to RGBA.
The original `image 0.25.10` crate generates independent thumbnail references.

Run `scripts/reference-export-backgrounds.ps1`. It verifies the frozen source
and checks that the original method text remains unchanged before running the
locked Rust tool. The result is 10 light/dark effect rasters, five thumbnail
rasters and the original grayscale bytes. SHA-256 provenance is retained in
`reference/background-pixels.json`.

These are small, deterministic algorithm references. They are not screenshots,
they do not launch any GUI, and they do not establish native UI visual parity.
The Go port matches all generated bytes, including the current image crate's
CICP sRGB luminance conversion. Other embedded image color profiles still need
platform acceptance testing.

image crate's MIT-or-Apache-2.0 implementation. Its MIT text is embedded as
`internal/assets/data/artifacts/notices/image-thumbnail.MIT`.
