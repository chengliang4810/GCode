# 应用用量

左下角用量图标打开设置页的「用量统计」，设置导航和搜索也能进入。
页面参考本地 `D:/projects/ZCode/packages/ui/src/settings/usage-stats/AppUsagePanel.tsx`
及相关图表，采用 GCode 共享设置页框、主题和控件；不包含个人套餐、余额或供应商额度查询。
原有四项 Token 合计弹窗及其开关状态已删除。

页面包含五项累计指标、最近 52 周活跃热力图、7 天／30 天模型趋势、模型占比及刷新。
累计指标不随范围切换变化；热力图提供每日、每周、累计三种模式。
图表原生绘制，悬停可读取具体日期和用量，模型列表显示比例及 Token 数。
超过六个模型时保留前五个，其余归入「其他模型」，趋势与占比使用同一组颜色。
趋势图例、日期提示和占比列表统一显示「供应商名称/模型名称」，复用当前模型目录的名称解析；
统计仍按完整内部模型 ID 分组，不合并不同供应商的同名模型。
已移除模型保留记录中的完整请求模型 ID，并解析仍存在的供应商名称；
供应商也已移除时保留原始标识，不推断其名称或改写历史记录。

## 统计口径

- 数据来自当前宿主快照中保存的会话消息与执行记录，包括归档、子会话。
  删除会话会移除相应消息用量；这不是独立保留已删除记录的计费账本。
- 总 Token 为输入加输出。缓存输入是输入的组成部分，不再次加进总量。
  只累计已记录数值，不估算未上报用量，不请求个人套餐接口。
- 每条实际助手消息记录 `ModelID`，切换会话模型不会改写此前请求的归属。
  缺少模型记录的用量归入「未知模型」，不增加旧格式迁移或根据当前模型推断历史。
- 分叉会重新生成消息 ID，但保留执行 ID 与消息顺序。按执行中的步骤去重，
  同一执行的多次模型调用仍分别计入；已完成执行的时长按原始会话累计，
  取最大值为「最长会话」，不把会话闲置时长算进去。
- 单日峰值与连续使用天数按客户端本地自然日计算，以 Token 大于零作为活跃日。
  今天无用量时当前连续天数为零；日期窗口使用日历运算，覆盖夏令时变化。
  缺少日期的记录保留在累计总数中，不虚构日期进入趋势和热力图。
- 桌面在后台根据不可变快照构建展示投影，通过窗口调度提交结果。
  本机仍使用强类型 Go 核心接口；远程连接使用该远程宿主的快照，不复制业务执行逻辑。
