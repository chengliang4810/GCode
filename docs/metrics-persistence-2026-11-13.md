# 核心统计持久化与同类问题排查

## 最终行为

- 核心在会话数据变更的提交路径维护自有统计、包含委派的对话总计及各运行统计，和会话记录通过同一索引事务提交。
- 已结束统计在重启后直接读取，滚动、悬停、切换主题和首次查看均不重新遍历原始消息、模型请求或工具记录。
- 活跃尾区间保存起点，界面仅按整秒计算正在增长的读数；完成后保存固定区间。并行执行取区间并集。
- 子智能体用 `ParentRunID` 归属父运行。未加载的父会话根据已存自有汇总与子汇总组合，不读取父正文。
- 取消、失败、手动压缩、删除子会话及宿主重启均更新相应投影。重启冻结未正常结束的计时，不根据现在的时间推算过去。
- 汇总随提交索引保存，原始明细留在会话记录；某历史根不可写时保留该会话已提交的统计，再组合祖先和应用用量报告。

## 同类路径

| 路径 | 处理 |
| --- | --- |
| 对话、回复用量/耗时 | 删除 UI 汇总和内存统计缓存，直接读取 `Snapshot.Metrics` |
| 智能体用时 | 读取持久化自有时长，不逐帧扫描、排序与合并全部 Runs |
| 运行活动摘要与消息时长 | 核心保存 `Run.Summary`、消息的执行时长；compact 标题不扫描 Runs 回退 |
| 局部活动分组摘要 | 属于展示分组，按正文投影内容变化计算一次；变化指纹包含工具类别及失败状态 |
| 已结束活动的入场动效 | 不再为静态历史生成每帧的时间数组与逐行进度数组 |
| 应用用量报告 | 核心保存紧凑台账、日/模型报告与总计；服务直接返回报告，不把历史汇总工作交给客户端 |
| 用量图表范围 | 缓存报告对应的热力图日期、窗口和模型列表；改变范围只更新展示投影 |
| 智能体树、分支增删计数、待办摘要 | 按数据版本或权威待办变化更新，不随滚动重算 |

原始统计精度保留，所有界面耗时仍使用统一 `i18n.Duration` 整秒格式与原有等宽数字控件。

## 边界

历史记录若原本没有新汇总字段，不增加 UI 回退，不自动迁移、重建或改写真实用户 profile。后续正常的会话数据提交会按当前结构维护汇总；本轮没有安装应用。

本轮修复统计及静态投影的重复计算。展开工具组本身仍有正常的布局和绘制工作，不把统计修复等同于已证明原生滚动完全流畅。
