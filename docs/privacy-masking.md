# 模型请求脱敏

2026-11-16：在「设置 → 隐私与脱敏」提供总开关，默认关闭。
关闭时不执行识别或响应还原，不下载、不加载本地识别模型。
开启后，策略在下一次模型请求绑定时生效；已经发出的请求继续使用其接受的设置快照。

## 配置

| 配置 | 行为 |
| --- | --- |
| 密钥与密码 | 原项目内置的 API 密钥、私钥、令牌、密码及连接串识别 |
| 保持密钥格式 | 对支持的密钥生成同格式虚构值，回复时还原 |
| 个人信息 | 邮箱、电话、身份证件、银行卡；可独立选择 SSN、护照、IBAN、出生日期、MAC、序列号、主目录用户名、用户与主机、公网 IP、云存储桶 |
| 自定义敏感词 | 每行一个；可选忽略大小写、整词匹配 |
| 自定义规则 | 类型标识 + 前缀或 RE2 正则；支持添加、编辑、删除；第一个捕获组作为敏感值 |
| 放行名单 | 忽略大小写的完整值匹配；沿用原引擎语义，自定义敏感词和已脱敏历史优先保持脱敏 |
| 处理方式 | 每个命中类型可选脱敏、警告、阻止；警告允许原文发送并提醒，阻止拦截整个请求 |
| 脱敏提醒 | 可选显示命中数量，不在事件或通知中显示敏感值；警告策略始终提醒 |
| 本地模型 | AstrLink Guard（默认选择）与 Privacy Filter；显式下载、取消、删除、选择和置信度设置 |

普通文本配置失焦保存，开关和选择器立即保存；自定义规则按添加/更新操作提交。
关闭总开关保留配置。

本地模型功能同样默认关闭。启用前须下载所选模型；未下载、加载失败、识别失败或
两分钟内不能完成识别时，阻止请求，不静默退回仅规则识别。
用户取消请求时传播取消信号。下载任务由宿主继续持有，客户端断开不取消；
用户可主动取消，宿主退出时停止下载。下载仅访问原项目固定的模型及运行时地址，
校验固定 SHA-256；模型权重不随 GCode 发布。

## 请求与还原边界

核心通过 `bindModelLocked` 为模型网关绑定设置快照。
主对话、侧聊、子代理、压缩、Hook 模型调用、自动命名和模型连接检查共用同一边界。
远程客户端更新的是远程宿主策略，本机 UI 不复制执行逻辑。

三种协议均在适配器完成真实供应商请求编码后、HTTP 发送前调用 `MaskJSON`，
因此覆盖系统提示、历史消息、工具输出、工具参数和工具描述。
供应商认证头正常发送；正文中出现的密钥仍按识别规则处理。
协议 ID、工具名称、Schema 字段及签名/加密内容遵循原引擎的结构保留规则。
图片、附件二进制、编码数据和签名/加密推理不是文本识别的承诺范围。

流式响应经过协议解码后，分别为可见文本和思考文本维护占位符尾片段，
防止分片导致还原失败。工具参数在完整响应验证后按 JSON 字符串语义还原；
引号、反斜杠等不会破坏参数结构，还原后的参数再次验证 JSON。
重试的每一次物理请求使用独立还原缓冲。

Agent、工具和本地对话持有原始值；协议私有 Continuation 保持供应商原始内容，
不修改其签名。Continuation 的作用域包含脱敏设置指纹，切换策略后不复用
另一套设置下的签名回放。请求诊断指纹来自真正发送的脱敏正文。

识别失败、阻止策略或脱敏结果无效时不发送原始正文。此功能减少文本中的敏感信息
外发，不能保证识别所有未知格式，也不清洗本地历史或模型调用记录。
