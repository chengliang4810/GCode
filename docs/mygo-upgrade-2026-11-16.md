# MyGo v0.9.1 升级验证

2026-11-16：GCode 从官方 MyGo v0.8.3 升级到 v0.9.1，固定上游提交
`13a0b3e7b3e161454889ff8e1bbf16ab6ffbbe0d`，本地修订 `rcode-native-ui.27`。
当前身份、补丁顺序及完整校验和以 [源码锁](../third_party/mygo.lock.json) 为准，
功能逐项处理见 [固定补丁](mygo-patches.md)。

## 实际改动

- 18 项补丁逐项重放并处理新版冲突，旧 v0.8.3 补丁文件删除；最终源码 2852 个文件。
- 富文本键盘、菜单与快捷键粘贴统一接到上游 OnKey/OnCommand，删除旧签名和 OnPaste。
  保留当前业务需要的输入法组合状态、显示文本快照、固定行高和内部边距。
- 保留分栏同帧尺寸写入，合入上游拖动越界时保留回退距离的行为。
- WebView2 数据目录接入新版拆分文件，保留无 WebView 构建路径；Windows 字形测试适配新增参数。
- 使用官方 migrate-ui 预览，针对应用 internal 应用 key 构造迁移；没有批量改写上游示例。
- 待办与目标附加面板删除上一帧高度缓存，由布局直接计算裁切，避免折叠后下一次点击时按钮移位。
- 目标 E2E 在重开编辑页前等待异步关闭完成；像素测试复用同一帧快照，避免逐像素重复获取整图。
- 同步构建版本门禁、许可证来源标识和当前文档。Ghostty 原生库清单及 MIT 原文逐字比较未改变。
