# 上下文压缩与缓存

2026-11-10 起，普通对话只追加已提交消息；删除旧式按轮次截短工具结果的微压缩。
必要的完整摘要压缩保留。实现参考成熟产品的前缀稳定性模式，没有引入新的运行时或依赖。

## 新结果的模型表示

- 不超过 32,000 字符的文本正常记录。
- 超限文本先完整写入会话原运行根的 `sessions/<id>/tool-results`，
  再生成固定预览与文件路径。预览保留工具返回正文的开头和尾部；通过 Read 的 offset/limit 或
  有界文件处理命令继续读取。原工具本身的分页/范围限制仍有效。
- Bash 前台和后台任务的合并输出超过原 64 KB 内存上限后，继续流式写入同一会话目录；
  stdout/stderr 展示缓冲保持有界。流结束时同步并关闭文件，保留真实退出和取消语义。
  命令预览是有界缓冲的节选；完整流的尾部可从输出文件继续读取。
- 落盘路径不使用模型提供的工具 ID 拼接。目录通过受限根句柄访问，拒绝软链接目录，
  文件以私有权限创建。输出不进入自动清理的临时或缓存目录。
- 写入失败不伪造文件引用：已完成的工具及其返回结果仍记录，本轮停止，
  不为了恢复存储而再次执行工具。

这些决定发生在第一次向模型发送之前。后续请求、存储与恢复直接重用已提交表示，
不会重新按预览模板或新的阈值改写旧消息。
工具钩子的指令在预览之外完整保留。钩子替换或脱敏结果后不再返回原始输出文件路径。

## 去重范围

Read 按本次真实返回的内容摘要去重，不依赖文件名或 mtime 猜测内容未变。
图片按内容、MIME 和尺寸确认一致。只有原正文或原图片仍存在于当前模型上下文时，
新结果才可以引用先前的工具结果。

引用消息不充当新的原始内容。完整摘要压缩移除原内容之后，再次读取会重新返回内容；
恢复会话从保存的上下文判断，不持有一个永不失效的“已经读过”缓存。
工具照常执行，只有模型输入表示去重；不会跳过真实读取或有副作用的工具。

## 自动与手动摘要

自动压缩使用最近一次真实供应商 input/output usage 作为锚点，并估算新增消息。
`model.Usage.Input` 已含缓存输入，不再另加 Cached。
未知 usage、改变模型/思考/提示/工具或消息位置变化时，改用当前内容的保守估算。
容量未知时不自动触发。

触发前从容量中扣除实际配置的请求输出上限，再留出下一步工具结果增长空间；
未知输出上限时采用受限的窗口比例预留。阈值是执行保护，不是供应商实测 token 数。

生成摘要时沿用主对话的系统提示、工具、思考配置和原消息前缀，在尾部追加摘要任务。
普通摘要只有一次模型调用。分层上下文折叠要求摘要去除首尾空白后为 1–8000 个字符，
且确实缩小所选历史；校验不通过时，携带具体原因与字符数重新生成，最多三次模型调用。
重写沿用同一段原始历史，不截断摘要；只有校验通过才提交折叠结果。连续三次无效、
模型请求错误或返回工具调用时保留原上下文及归档，并停止本次压缩；不执行返回的工具调用。
摘要替换完整前缀，保留最近完整工具交互；输入归属 ID 和保留消息的私有续接状态继续保存。
手动 `/compact` 使用会话保存的最近请求前缀，业务状态不从轨迹文件恢复。

Anthropic Messages 使用标准内容块缓存断点；摘要指令本身不写入消息级缓存。
OpenAI Chat/Responses 不发送 Anthropic 缓存字段。生成摘要可能复用旧前缀，
但摘要替换历史后的对话仍需建立新前缀，不能保证缓存命中或费用下降。

## 观测与验收

轨迹区分完整 wire body 摘要、系统/工具/请求参数/目标变化、消息前缀变化，
以及图片字节量、上传结束、响应头到达、首个输出和上游请求 ID。
缓存标记位置变化不被当作正文改写；真实请求体的任何变化仍反映在 body SHA-256。
主动压缩和摘要的预期重建单独记录；无 usage 的失败不作为零命中。

确定性测试覆盖三协议真实 HTTP 编解码与 Go 文件工具、稳定预览/去重、
摘要配置保留、超限命令流、存储失败、会话重启、数据根切换及目录软链接拒绝。
这些测试使用本地供应商夹具；实际供应商命中率、价格、延迟变化需要运行新版本后另行观测。
