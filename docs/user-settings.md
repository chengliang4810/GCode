# 用户级 Agent 设置

模型选择器统一为输入栏上方的两列菜单，不再提供紧凑模式开关或首层选项页。
菜单以模型按钮为锚点，底边与按钮上沿相隔 6 像素；新建对话、已有对话及多行草稿
使用同一定位规则，不随输入框高度变化额外上移。菜单作为浮层覆盖输入区域。
供应商菜单与模型按钮中线对齐；模型子菜单优先向右展开，右侧空间不足时向左展开。
供应商行的箭头固定朝右。两列从顶部对齐；各列宽度按供应商名和模型名的实际
测量结果计算，模型列最小 192 像素，整体受窗口宽度限制，避免固定分栏截断模型名。
供应商菜单直接显示用户配置的名称，底部固定「模型管理」入口；子菜单显示该供应商的模型。
供应商仅筛选模型列表，选择模型后才更新会话并关闭菜单；Escape 直接关闭。
供应商和当前模型使用勾选标记，左右列表可独立滚动；窄窗口中两列同时收缩。
模型行不提供逐行设置按钮；模型编辑统一从供应商菜单底部的「模型管理」进入。
模型收藏、收藏字段与快捷键已移除，`Ctrl/Cmd+1…9` 不再选择模型。

输入栏的模型按钮只显示请求模型 ID，模型行不再显示厂商副标题或数字快捷键。
当前供应商超过 7 个模型时自动显示搜索；少量模型可在菜单内按 `Ctrl/Cmd+F` 展开搜索。
搜索支持上下键和 Enter，目录使用虚拟列表。
思考强度继续通过模型按钮旁的独立滑块选择器调整，没有档位时隐藏该入口。
快速模式和其他模型选项保留在模型列表底部，不在模型菜单内重复显示思考强度。
通用设置中的「紧凑模式」仍只负责折叠思考与工具，和模型选择器无关。
外观页的「思考强度主题」为滑块提供跟随主题、紫色、陶土橙、深蓝、天蓝、
极光渐变、银白、金色八种预设；每项在触发器和下拉行中显示三色渐变胶囊。
预设只保存在本机外观设置 `effortTheme`，不改变应用主题、强调色或模型选项；
「跟随主题」读取当前强调色，其余预设与应用主题无关。滑块填充按预设三色
从左到右取样，未达到的刻度点用中性色，填充后的刻度点使用与预设对比的
黑色或白色。默认预设为紫色。

设置页提供模型设置、插件、子智能体、MCP 服务器、技能、命令、钩子入口。
模型页使用供应商列表与详情双栏，连接字段直接编辑；单模型添加和配置使用模态窗口。
模型模态平铺模型 ID、上下文窗口、最大输出、输入类型和推理等级，
没有高级折叠或模型能力区；底部固定重置、取消和保存按钮。
智能配置始终启用，不提供开关、加载文案或匹配提示。新建模型上下文窗口为 200000、输出为 12800；
这些默认值可以被匹配到的缓存元数据或手动输入覆盖。编辑已有模型保留已保存值，
修改模型 ID 或重置表单时自动匹配，不在打开编辑器时覆盖手动配置。
输入类型包括文本、图片、音频、视频、PDF，文本固定选中；这些是配置元数据，
不新增媒体上传或解析流程。推理等级按 `none/minimal/low/medium/high/xhigh/max` 顺序勾选，
不是默认全部启用，Messages 协议仍不接受 `minimal`。

智能配置只查询宿主运行根 `cache/gcode/models-dev.json` 的本地索引，查询不会访问外网。
内置从 `https://models.dev/api.json` 下载的 JSON 快照保证首次离线启动可用；
宿主运行期间每 3 小时在后台条件请求一次同一站点，使用 ETag/Last-Modified，
完整校验成功后才原子替换文件。HTTP 失败、无效 JSON 或空目录保留上次有效数据。
`models-dev-state.json` 保存刷新时间和条件请求标记，失败也记录尝试时间，
重启沿用剩余等待时间，已过期则在后台刷新，避免不断重启造成重复请求。
优先按供应商地址和完整模型 ID 匹配；相同优先级按供应商 ID、模型键排序，取第一个自动填充。
未匹配或本地查询失败时保留表单值，不显示额外提示。
自动填充只修改当前草稿，缓存刷新不会改写已有供应商和模型配置；远程模式查询远程宿主缓存。
子智能体、MCP、命令、钩子新增/编辑时切换到独立表单页，替换列表，提供面包屑返回。
技能详情和导入、MCP/命令导入使用模态窗口；资源及供应商删除先弹出确认。
单模型删除仍在列表直接执行。表单页与模态窗口不再作为列表下方的展开区域。
插件页提供用户、项目、local 安装范围；项目与 local 范围要求从宿主项目中选择实际目录。
独立维护的模型、子智能体、MCP、技能、命令与钩子仍属于当前业务宿主的用户配置；
连接远程宿主时，安装、更新与执行都由远程宿主负责。

本次只读参考 ZCode `3c5b227649371507ddc4eb46ac5133afe6db1cab` 的布局和使用流程，
以本项目 Go/MyGo 和真实 Go 核心独立实现，没有复制参考源码或引入其依赖。
原有视觉一致性工作仍暂停，这次只调整请求中的六页。

## 功能与执行效果

通知页保留桌面通知、仅在后台时及会话提示音设置。智能体由应用内 Go 核心实现，
已移除外部智能体 CLI 的“智能体更新”开关、设置搜索入口和 `agentUpdates` 配置字段。

| 入口 | 当前交互 |
| --- | --- |
| 插件 | 市场搜索/来源筛选、范围与项目选择；来源增删改和刷新；已安装插件启停、更新、卸载和配置 |
| 新增/编辑供应商 | 立即创建空配置，右侧直接维护名称、连接字段、启停；Enter 或字段失焦保存，草稿可显式保存/取消 |
| 添加/编辑单模型 | 独立模态窗口，取消不提交草稿 |
| 子智能体、MCP、命令、钩子新增/编辑 | 独立表单页；返回、取消或保存后回到列表 |
| 技能详情 | 独立只读详情模态，提供状态、真实宿主路径和编辑入口 |
| 技能目录导入 | 独立模态；导入目录和支持文件由宿主处理 |
| MCP/命令导入 | 独立模态，导入本项目当前 JSON 单对象，分配新 ID 防覆盖 |
| 供应商与资源删除 | 确认模态，确认前不修改核心数据 |

模态限制背景输入，支持 Esc、背景点击和关闭按钮；长内容在模态内滚动。
切换设置页会关闭旧页编辑器和对话框，保存失败保留对应草稿。

自定义子智能体列表使用独立卡片，显示名称、模型及思考档位、工具范围和描述。
点击行进入编辑页，右侧提供启停和删除；删除需确认，取消不会进入编辑或修改配置。
编辑页优先排列名称、模型和思考档位，窄窗口自动换行；字段有固定标签和就地错误提示。
工具区先选择全部默认工具或自定义范围，只有自定义时展开网格；显式范围不能保存为空。
随后配置系统提示词和项目指令开关，底部提供保存、取消及编辑已有项时的删除入口。
名称、描述和系统提示词必填；保留本项目对中文显示名的支持，不照搬参考的文件名限制。
保存期间保留表单、禁用重复操作，宿主确认成功后才返回列表；失败保留草稿与错误供重试。
这些布局和提交调整只用于自定义类型，内置类型的现有编辑与启停语义保持不变。

供应商列表和供应商内的模型列表通过行首拖拽手柄排序，拖到目标行上半部放在其前，
下半部放在其后；指示线标明落点，Esc 取消。模型不能跨供应商拖动。
模型行只显示请求模型 ID，不再维护独立显示名称。
松开后由业务宿主按当前 ID 顺序保存，重启后保留；聊天和子智能体模型目录沿用同一顺序。
排序只移动条目，保留 API Key、连接字段、模型元数据和当前表单草稿。
保存期间暂停新的排序，失败显示错误并保留原顺序。

| 页面 | 维护功能 | 保存后的实际效果 |
| --- | --- | --- |
| 插件 | 市场目录、来源、安装范围与配置 | 通过类型化命令维护实际宿主插件；列表只显示宿主快照，凭据值不进入快照 |
| 模型设置 | 自定义供应商、三协议、Base URL、API Key；模型 ID、上下文、输出上限、输入类型、思考档位及本地缓存智能配置；拖拽排序、供应商启停；模型行仅提供测试、编辑、删除图标 | 主会话与子 Agent 共用配置目录；禁用项从可选模型中排除，直接调用也拒绝；已有运行使用启动时快照 |
| 子智能体 | 内置类型编辑/启停；自定义类型增删改；搜索、提示词、继承或指定模型/档位、选择工具、是否注入项目指令 | 内置目录始终显示，保存配置按 ID 覆盖；父运行冻结启用的类型；真实子会话使用选定模型和工具，关闭项目指令注入后不加载项目 AGENTS.md；Explore 仍限读取搜索 |
| MCP 服务器 | stdio/Streamable HTTP；表单与 JSON；命令及参数、环境变量、URL/请求头；增删改、启停、连接测试及工具列表 | 新运行连接启用服务器并注册真实工具；测试执行初始化及工具发现；配置变更使旧测试失效 |
| 技能 | 创建、编辑 SKILL.md、从宿主目录导入、支持文件、搜索、启停、删除、刷新 | 模型通过 `Skill` 加载正文；用户通过 `/name` 或目录内的 `/skill:ID` 显式调用，遵循 frontmatter 调用限制 |
| 命令 | 名称、描述、参数提示、提示词；搜索、增删改、启停、刷新 | `/name 参数` 展开给模型，聊天显示原始输入；支持 `$ARGUMENTS`、从 `$0` 起的索引及声明的命名参数 |
| 钩子 | 从共享事件定义生成事件目录；command/http/prompt/agent/mcp_tool，匹配、参数、超时、异步、条件及失败策略 | 使用 Claude 事件/输入输出契约执行；不支持的事件/类型组合明确提示并由执行器跳过 |

内置子智能体类型为 `general-purpose`、`Explore`、`Plan`、`claude`。
Explore 与 Plan 保持只读工具边界，自定义类型仍支持独立增删改。
插件中的 `sonnet`、`opus`、`haiku` 和 `inherit` 在当前执行上下文中继承模型；
明确指定子智能体类型时，优先采用用户为该类型保存的模型配置。
工具列表使用当前公开名称，如 `Read`、`Glob`、`Grep`、`Bash` 和 `AskUserQuestion`。

钩子的 shell 和直接程序执行都属于 `command`：参数为 nil 表示 shell，
非 nil 的空参数数组也明确表示直接程序执行。编辑器使用独立选项保存这一区别。
超时秒数保留小数（例如 0.25），不截断为整数；拒绝负数、NaN 和无穷值。
HTTP 请求头、允许环境变量和 MCP 输入可用 JSON 字段编辑，这是用户配置解析，
不会成为本机 UI 与核心之间的传输层。

供应商 API Key 在编辑时留空保留。MCP 的环境变量/请求头值不进入公开快照；
未提交的键保留原值，显式删除键才移除。测试和真实 MCP 调用统一脱敏配置凭据。
模型测试结果只发布本地分类及 HTTP 状态，不发布可能回显凭据的服务端错误正文。

供应商允许暂不填写 Base URL 或不添加模型，也允许删除最后一个模型。
待配置供应商仍保存在用户目录中，但不会进入聊天/子智能体模型目录，直接执行也拒绝。
左侧绿色状态点只代表连接字段和启用模型配置齐全，不代表已通过网络连通性测试；
橙色为待配置，灰色为禁用。API Key 可为空，以支持无需鉴权的本地服务。
密钥显示按钮优先切换本次输入的草稿；草稿为空时，显式请求宿主读取已保存密钥。
公开快照不返回已有密钥；
保存成功清除输入，失败保留当前草稿，切换供应商不会让迟到回调覆盖另一份编辑。

模型测试由按钮显式触发，使用所选模型发送最短探测请求，最多输出 64 tokens，
30 秒超时，不创建聊天、Agent 或工具执行。该请求可能产生供应商计费；
它不代表完整模型能力验证。保存/删除配置会取消旧探测，迟到结果不能覆盖新配置。

技能导入复制到受管目录，保留相对支持文件；不引用原目录持续运行。
上限为 256 个文件、8 MiB，总入口 SKILL.md 必须是最多 256 KiB 的 UTF-8 文本。
拒绝符号链接、非法相对路径及路径逃逸，修改正文保留已导入支持文件。
列表和编辑器中的名称/描述是用户目录元数据，SKILL.md 正文由用户独立编辑。

## 钩子约定

事件目录、处理器、默认 shell、输入输出及实际触发边界见 [钩子运行](hooks.md)。
当前使用 Claude 公开事件名和 `command/http/prompt/agent/mcp_tool` 定义，
不再使用旧 `process` 类型。`command` 的非 nil 参数数组表示直接执行程序，
省略参数数组表示 shell；Hook 默认 shell 与 `Bash` 工具是各自独立的契约。

真实用户输入触发 `UserPromptSubmit`；目标续跑和子任务通知属于宿主上下文。
`PermissionRequest` 只在策略确实要求询问时触发。当前核心默认权限模式对应
`bypassPermissions`，不虚报已实现 Claude 自动权限分类器。
工具前 Hook 可以修改实际参数；工具后 Hook 不能撤销已经发生的副作用。
Stop/SubagentStop 的阻止或附加上下文会继续执行，连续最多 8 次。
异步结果通过真实会话队列返回，停止与关闭由宿主取消并收尾其拥有的进程。

不会改变这些配置路径，也不会复制旧数据。切换在重启后生效，新会话使用新根，
已有会话的续聊、执行和附件继续写入其原有根。工作树目录不再单独设置，

MCP 核心支持 stdio、Streamable HTTP 和旧 SSE；OAuth 协议能力与原生登录界面的
完成状态分开记录。未连接的组件与认证依赖如实显示，不等同于插件已运行通过。

与参考仍有明确适配差异：ZCode 新建技能转到带 skill-creator 引用的新聊天，
详情中的编辑动作打开文件管理器；本项目保留已经可用的手动创建和正文编辑模态，

这里 MCP/命令采用本项目当前 JSON 结构的显式导入，不解析其他程序的配置格式。

## 参考文档与代码差异

ZCode 当前代码与其诊断文档有两处明确不一致：

- `diagnosing-hooks/SKILL.md:32` 声称 async 无实际效果，但
  `core/src/hooks/runner.ts:125–153` 已在后台运行。
- `diagnosing-commands/SKILL.md:34,56` 声称动态 shell 被拒绝，但
  `bootstrap/src/custom-command-prompt.ts:41–69` 在存在 executionPort 时执行展开。

参考的命令服务列表先项目后用户，而 CLI 实际发现先用户后项目。
当前按 Claude 公开规则解析项目 `.claude/skills`、`.claude/commands`、
`.claude/agents`，项目同名资源覆盖个人资源；插件资源使用插件命名空间。
旧文档中的“只有用户级目录”“不支持动态 shell”“七个事件”和一基参数占位
已经不符合本次实现，上文已同步修正。历史验收日期下的结果仍只对应当时版本。
