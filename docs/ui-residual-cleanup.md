## 行为与成本

- 模型命名默认不增加请求。显式选择模型会增加一次独立命名请求，限制输入长度、
  输出预算和时间；失败保留初始标题，用户手动改名不会被迟到结果覆盖。
- Git 操作在核心锁外执行。新工作树使用 `feat/` 分支；未接受任务时，仅安全回收
  本次创建、原提交未变且完全干净的工作树。复用、已接受或发生变化的工作树不删除。
  当前检出保留用户选定的项目子目录；无 Git 项目不附带无效 checkout 计划。
- 系统通知只在桌面客户端发出，Linux 无桌面服务不依赖 MyGo。用户侧聊和分叉
  正常通知，自动子 Agent 不单独制造通知洪泛。操作系统拒绝通知或音频输出失败
  会记录错误，不阻塞任务。
- 壁纸读取不修改桌面设置。Linux 按当前桌面环境选择 GNOME、KDE 或 XFCE 来源。
  取色失败时保留原主题并在设置行显示错误。
- 数学排版支持常用符号、分式、根式、上下标及样式。未知宏、无效输入或超出
  渲染器尺寸预算的公式保留源码，不声称支持完整 LaTeX。图片、链接、代码、
  HTML 等现有 Markdown 内容不能因包含公式而丢失。

## 验证边界

独立数据目录，不读取用户真实凭据。原生桌面测试通过 MyGo Automation 驱动
独立窗口，检查设置持久化以及命名、工作树和消息显示链路。

通知的事件分类、去重与取消通过注入接收器验证，尚未把测试横幅或声音发送到
用户桌面。Linux/macOS 的系统通知、壁纸来源和桌面渲染仍需对应平台实机验收。
当前环境无可用 C 编译器且禁用 CGO，未运行 Go race 检测。
