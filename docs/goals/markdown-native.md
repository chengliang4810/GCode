# GCode 原生 Markdown

GCode 对话消息使用 `github.com/yuin/goldmark/v2` 的 CommonMark/GFM parser，将 AST 转换成桌面 UI 专用的不可变渲染模型。UI 线程只读取已完成模型；生产窗口通过 `App` 的 dispatcher 在后台解析，流式消息按消息 key 和源码文本校验，迟到的旧解析结果不会覆盖最新文本。

支持标题、段落、转义、嵌套列表、有序列表、引用、粗体、斜体、删除线、行内代码、链接、GFM 表格、围栏代码块和缩进代码块。代码块使用 Chroma 语法高亮，并对长代码和表格提供原生横向滚动。消息和代码块都能复制原始文本。

解析模型不保留 Goldmark AST 或输入字节切片。Markdown 图片不下载资源，显示明确的 `[图片未加载：替代文字]` 占位文本。原始 HTML 始终作为文字显示，不经过 WebView、HTML 注入或脚本执行；链接只构建 `ui.Link`，仅在用户点击或键盘确认时交给 MyGo 的安全打开行为。

正文使用 15.5 DIP、1.55 行高，代码使用 13 DIP 等宽字体。空消息继续由对话层显示生成状态，非空流式消息在后台模型尚未完成时先显示原文，完成后刷新为结构化渲染。

可选择的正文、原始 HTML 文本和代码块显式使用主题的选区颜色。内联代码使用代码面的前景色和背景色，代码块复制按钮沿用代码前景色，确保浅色主题中代码内容和控件保持对比度。
