# /goal：设置页保存服务的即时派生状态反馈

状态：已完成。

目标：模型服务保存成功后，控制器快照中的 `Provider.HasAPIKey` 能在当前设置编辑器中立即反映；用户正在编辑的服务字段、主题、发送方式、密钥输入和当前选中服务不被快照覆盖。

实现边界：`App.updateSnapshot` 在存在脏设置草稿时，只按当前 `Provider.ID` 从服务器快照同步 `HasAPIKey`。没有匹配服务时保留草稿原值；普通设置快照仍按原有规则重建未修改的草稿。

完成判据：

- 保存成功快照将当前服务的派生密钥状态刷新为已有密钥。
- 保存失败保留编辑草稿，不报告凭据已配置。
- 保存期间产生的较新服务字段、主题、发送方式和密钥输入继续保留。
- 切换到其他服务后，迟到的快照只更新匹配服务的服务器数据，不改变当前编辑器。
- 不增加兼容路径、迁移方案或配置项。
