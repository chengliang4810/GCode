## 明确保留的实现差异

- GCode 本机 UI 与核心直接使用 Go 类型；RCode 的远程调用机制不复制到本机路径。
- GCode 提供完整会话快照，RCode 分页/历史回放专用水位不照搬。
- GCode 已有验证中、预算耗尽、预算和未知用量信息继续保留，不因参考只有三种状态而删除功能。
- 控件沿用 GCode 共享规范；系统减少动效下使用静态活动反馈，不照搬 RCode 的缓慢亮度脉冲。
