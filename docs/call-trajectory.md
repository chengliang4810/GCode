# 对话调用轨迹

对话标题右键选择「调用轨迹」，在右侧工作区打开绑定该对话的 Tab。
左侧对话列表的标题右键也有同一入口。重复打开同一对话会选中现有 Tab，
支持与文件、网页、终端等标签共存；关闭轨迹不会关闭中央对话或改变其草稿。
标题重命名会更新标签，删除对话会关闭其轨迹标签。

参考来源为本地只读 `D:/projects/ZCode` 的 `ModelTrajectoryPane.tsx`、
`ModelTrajectoryPaneParts.tsx`、`ModelTrajectoryTimeline.tsx` 和服务侧
`modelTrajectory.ts`。保留原生 Go/MyGo 及现有共享控件规范，
没有引入 React、WebView 或 ZCode 的 JSONL/跨进程访问方式。

## 内容与操作

每次实际 HTTP 尝试记录时间、时长、协议、模型、供应商、来源、执行 ID、
尝试序号与 HTTP 状态。展开后查看规范化请求中的系统提示、各角色消息、
工具定义，以及模型输出、推理、工具调用、用量与错误。
请求历史来自实际模型输入，不从可见聊天气泡重建。
请求头、供应商凭据和附件原始数据不会进入轨迹。

支持按内容搜索、请求/响应/消息分层折叠、全部展开/折叠、刷新和复制结构化调用。
搜索只保留命中调用，并展开命中的内容块。未知用量显示未上报；
不根据文字长度估算 Token。失败调用保留错误，流中断时保留已解码的部分输出。
进程中断留下的未完成记录在读取时标记为无完成记录，不能当作仍在执行。

主对话、子 Agent、手动压缩和命名模型均接入记录。子 Agent 的记录归属于它自己的
会话；父对话不把其他会话的调用混进来。自动压缩、验证与 Hook 模型调用使用各自
所属的已绑定模型入口，来源跟随该入口。
HTTP 429/5xx 重试逐次记录，和现有用量计量记录各自保持职责。
历史对话未产生过这些记录时显示空态，不生成模拟轨迹或执行旧格式迁移。

## 存储与边界

轨迹位于对话创建时绑定的运行根：

```text
sessions/<session-id>/trajectory/call-<started-nanos>-<request-id>-<attempt>.json
```

每个对话最多保留 200 次 HTTP 尝试、32 MiB。每条记录上限 2 MiB，
单个文本字段上限 64 KiB；超限会明确标记省略，附件只保留类型和尺寸。
保留策略独立于通用日志清理，不改写会话历史。显式删除对话时清理所属轨迹，
不递归删除目录或移除未知文件。根句柄与真实目录检查阻止路径逃逸和目录别名。
诊断写入失败通过轨迹读取错误呈现，不改变模型调用结果。

完整上下文会增加本地磁盘写入及保存的业务内容；上限和省略提示用于控制该成本。
复制调用只复制已脱敏的记录。除配置供应商凭据的精确替换外，不声称能识别用户
提示、代码或工具输出中所有种类的业务秘密。

本机通过 `contracts.ModelTrajectoryService` 直接调用 Go 核心，在后台按需读取，
结果通过窗口调度提交。正文不进入快照或广播事件。
远程客户端只在真实连接边界访问认证后的 `GET /v1/model-trajectory`，
从拥有会话的宿主读取相同记录；不通过桌面客户端本地文件路径访问远程数据。

正常启动支持 `--route trajectory/<session-id>` 打开相同工作区 Tab。
这也是原生测试打开轨迹的生产路由。

## 验证

- 三种协议的真实核心工具循环：第一轮工具调用、第二轮包含工具输出的请求上下文、
  模型响应以及独立记录的重启恢复。
- 模型层验证 HTTP 重试、部分响应、凭据替换和附件数据省略；核心验证空历史、
  对话身份、保留上限、未完成记录及删除时保护未知文件。
- 远程核心验证认证连接中的运行中调用、断线后完成、重新连接后的轨迹读取，
  以及无效对话身份拒绝。
- `ui.Tester` 验证标题右键、标签显示、展开/折叠、搜索、复制、刷新错误保留旧结果、
  关闭标签及中央对话保持。
- `TestDesktopLocalCallTrajectory` 使用独立数据目录、本地 HTTP 模型、真实 Read
  工具读取临时文件、HTTP 400 失败及重启后的原生窗口，覆盖英文浅色与中文深色窄窗。

MyGo Automation 不支持选择系统右键菜单；右键入口以组件测试验证，
原生测试通过正常 `trajectory/<id>` 路由进入同一实现，再验证 Tab 和内容操作。
这不代表真实供应商、系统菜单输入、跨平台实机或视觉一致性验收。
