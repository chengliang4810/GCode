# 模型列表导入

「拉取模型列表」使用共享次级按钮，与「添加模型」相隔 12 DIP。
点击后立即弹窗，框内显示请求进度、失败重试或空结果。
返回列表后使用宿主已有的模型目录查询参数，新模型自动填充；已有模型保留已保存参数。
查询在后台执行，关闭弹窗会取消参数查询，迟到结果不会重新打开弹窗。

每个模型固定一行：勾选框、模型 ID、「上下文」输入框、「图片」勾选项。
默认全选，顶部全选框可取消或恢复全部勾选；没有反选按钮、已配置标记或未匹配备注。
已有模型与新模型均可编辑。保存时更新勾选的已有模型、添加勾选的新模型；
未勾选的已有模型保持原值，不因取消勾选而删除。
已有模型只更新上下文与图片能力，保留输出上限、定价及其他输入/推理配置。
单模型编辑页保留完整字段。

中英文、900×600 窗口、单行几何、先弹窗、全选切换、两类模型编辑与落盘。
