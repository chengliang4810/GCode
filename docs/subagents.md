# 子 Agent

本实现早期参考本地 ZCode 的 Agent/profile 行为，当前工具与插件类型接入按 Claude 公开定义
及本地只读参考调查，用本项目 Go 核心和原生 MyGo 独立实现；没有复制参考源码，
也没有增加 Node、Electron、RPC 或其他本机进程间业务路径。
ZCode 的工作流、`ListModels`、`subagent_model` 和 `$level` 语法不在这条路径中。

## 设置与选择

1. 设置 → 服务商：逐模型保存 请求模型 ID、容量、输出上限、输入类型及思考档位。
2. 设置 → 子 Agent：新增或编辑类型的名称、描述、任务提示词与模型。
3. 选择“跟随主模型”，会连同主运行的思考档位一起继承。
4. 选择具体供应商/模型后，只显示该模型声明的档位；无档位时隐藏控件。
   主动切换模型会选取新模型配置数组最后一项。恢复已有失效选择时显示不可用，
   不偷换默认值；缺失模型、无效档位或缺失必选档位会阻止启动。

可执行模型目录与主会话共用同一份用户配置，不内置可选供应商品牌或官方模型。
models.dev 本地缓存仅向编辑表单提供元数据建议，不把缓存中的条目自动加入可执行目录。
支持的档位 ID 为 `none/minimal/low/medium/high/xhigh/max`；声明哪些必须依据实际服务。
Messages 不接受 `minimal`。`none` 是明确的关闭选项；空值表示未指定，
新选择会取最后一项；没有档位的模型不会发送思考参数。

自定义类型列表直接展示模型、档位和工具范围，整行可进入独立编辑页。
表单按名称及模型、描述、工具范围、系统提示词、项目指令开关组织，
窄窗口自动换行。默认工具不展开明细，自定义范围按需展开且不可保存为空。
保存使用带请求 ID 的设置命令，表单一直保留到宿主成功确认；失败就地显示并保留草稿。
操作中的保存、返回、取消和删除入口禁用，避免重复提交；编辑页和列表都保留确认删除。
具体字段和用户级范围见 [用户级 Agent 设置](user-settings.md)。

内置目录始终提供四种类型，ID 大小写有意义：

| ID | 默认职责 |
| --- | --- |
| `general-purpose` | 一般编码、调查和验证 |
| `Explore` | 只读文件调查与搜索 |
| `Plan` | 只读需求调查与实施规划 |
| `claude` | 使用独立执行上下文完成一般委派 |

默认均继承调用方的有效模型与思考档位。
用户设置中的同 ID 配置覆盖内置类型，其他 ID 为自定义类型；设置为空时仍提供内置目录，
页面与运行启动使用同一份合成规则。内置类型可编辑和禁用，不提供删除操作；
删除仅用于自定义类型。禁用通过显式配置保存，不会被内置目录重新启用。
若希望固定分工，可按职责命名类型，并在设置中分别绑定供应商、模型和档位。
主模型通过工具声明中的类型 ID、名称和描述选择类型，完整供应商配置和凭据不会注入
模型上下文。公开 `Agent` 工具使用：

```json
{
  "description": "调查调用链",
  "prompt": "查找指定功能的入口及相关文件，给出证据。",
  "subagent_type": "Explore",
  "run_in_background": false,
  "model": "haiku"
}
```

`description` 和 `prompt` 必填；省略类型时用 general-purpose。`model` 可选，
只接受 sonnet/opus/haiku/inherit；它们是虚拟角色，不创建虚假模型目录项，也不会直接发送
这些名称给供应商。目前所有角色映射到调用方当前的有效模型与思考档位；
若用户为指定子 Agent 类型配置了模型，配置优先。
子 Agent 已选择模型 B 后，其内部技能的角色别名继续继承 B，不回到主对话的模型 A。
模型选择在运行接受时冻结，失效配置报错，不静默换模型或供应商。

没有单次 effort 参数。提示词写“max 思考”不会改写 API 等级，应在类型设置中选择。
相同模型不保证达到 Claude 原角色的速度、价格、工具调用质量或插件效果。
插件及项目的 agents 定义按名称加载，显式用户 profile 按同 ID 覆盖。

## 运行与显示

每个子任务拥有独立 Session、Run、执行历史、取消状态和实际模型/档位快照，
复用主会话的工作目录及同一个模型 Gateway。独立上下文不代表工作目录隔离；
多个写入型子任务需要由主 Agent 分配不冲突的工作。

父对话中的一行摘要显示类型名称、任务、运行状态，并打开真实子会话。
子会话侧面板为只读，显示实际模型/思考档位与停止按钮，不创建另一套业务逻辑。
不能从该子会话直接发送新消息或重试；用户主动 fork/创建侧聊得到的是新的普通会话。

前台任务继承父运行取消，父工具等待子运行完成收尾后取得结果。
后台任务独立于父回合取消，宿主负责其生命周期；父回合结束或远程客户端断开不停止它。
后台完成结果先进入持久化队列，在模型步骤边界交给活动父 Agent；
父会话已正常完成且空闲时自动启动后续回合。通知不伪装成用户发送的聊天消息。
父会话已被停止或发生错误时，完成结果保留到用户继续；已归档的父会话不自动唤醒。
删除父会话前必须停止其活动子任务，避免留下失去入口的运行。
后台任务仍可通过其子会话停止；也可用当前会话的 TaskOutput 读取/限时等待、
TaskStop 请求停止自有子任务。后台 Bash 与子 Agent 共享这些公开入口，实际执行仍由
各自宿主管理。宿主关闭会取消并等待全部任务。

目标执行另有所有权范围：主 Agent 等待已接受的子任务结束、处理结果后才检查目标完成，
等待期间仍能接收用户新输入。暂停或清除目标会取消其活动子任务；目标暂停、预算停止
或被清除后，迟到的子任务通知不会自动启动新的普通父回合。子任务用量计入目标，
详见 [目标执行](goals.md)。

最多同时执行 8 个子任务。子任务不注册 `Agent` 工具，不能递归委派。
Explore 与 Plan 的保留工具集合为 Read/ListDirectory/Glob/Grep，不开放写入、shell 或 MCP。
自定义类型、general-purpose 与 claude 使用普通集合，再按用户选择过滤。当前工具仍使用宿主 OS 用户权限，
这些限制不是 OS 沙箱。

用户级设置可禁用类型、选择工具子集，以及关闭子任务的项目指令注入。
禁用类型不进入父 Agent 工具目录。工具选择应用于实际注册集合，
并非仅修改提示词；Explore 仍只允许读取搜索工具。新设置的作用范围和六页布局见
[用户级 Agent 设置](user-settings.md)。

重启不重放不确定的副作用：未完成的 Run、子任务摘要标为中断，运行计数清零。
本版本没有自动恢复子执行或子 Agent 消息续聊工具。
插件技能的 context=fork 会通过真实 Agent 执行，agent 字段选择类型；缺省用 general-purpose。
技能 frontmatter 的解析、工具权限及 Hook 组合不等于已经逐插件验收完全兼容。

## 验证边界

本地 HTTP/SSE 夹具实际经过三协议适配器，覆盖跨供应商和 Max 请求、子任务文件写入、
结果回传、继承、配置快照、显式无效选型、取消以及后台结束后父 Agent 自动续跑。
另外覆盖重启计数、派生普通会话、启动持久化失败回滚、配置克隆与原生 MyGo 交互。
这些是确定性执行证据，不是已连接用户真实供应商，也不是原生实窗或视觉一致性验收。

2026-10-30 的当前契约专项覆盖四个内置 ID、模型角色参数及用户配置优先级，
既有三协议夹具已迁移；没有据此宣称真实供应商或官方市场 90% 已通过。
