# 子进程临时目录

会话启动的 Bash、命令 Hook、stdio MCP 和终端使用会话绑定的数据根，在
`tmp/processes/<sessionID>` 下存放临时文件。独立终端以终端 ID 为目录，
设置页 MCP 测试以独立测试 ID 为目录，使用创建时的活动数据根。切换默认数据根
不会改变已有会话的归属。数据根不可用时启动明确失败，不回退系统盘。

宿主只为这些子进程覆盖 `TEMP`、`TMP`、`TMPDIR`，不修改全局环境。优先级为
继承宿主环境、运行根默认值、用户显式 MCP `env`。Bash 的 SessionStart 环境文件和
用户执行的 shell 命令仍可以主动改变环境；交互终端的用户 profile 也可覆盖默认值。
命令 Hook 没有额外的公共 `env` 配置字段，运行根环境通过 Go 类型注入，不写入 Hook JSON；
Hook 协议拥有的 `CLAUDE_*` 字段保持其原有优先级。

`tmp/processes` 可能仍被后台任务持有，当前不做后台清理；它与可维护清理的
`tmp/gcode` 分开。环境默认值不是文件系统沙箱，显式路径、用户配置和外部程序仍可选择其他目录。
