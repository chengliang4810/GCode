# 核验后修复与决策（2026-11-05）

已完成不改变既定功能的修复，保留用户原有工作树改动。
原始外部审计文件未修改；仓库副本标注为历史材料。本页记录 2026-11-05 当时的结论，
其中 security-1/security-2 与落盘频率已被 2026-11-12 的后续提交取代（见下方修订说明），
其余结论以本页为准。

## 已交付

- 内存索引检查进入引擎锁，消除跨会话普通 map 无锁读取。
- 终端输入、尺寸、清屏在全局锁外执行，同一终端按序处理；关闭进程的等待也移到锁外，
  且仍纳入引擎关停等待。终端创建与创建失败回收仍走原有路径，本轮未重构。
- 窗口关闭回调启动后台业务关停，OnQuit/入口 Close 等待保存完成，避免提前退出丢存档。
  后续按用户选择接入桌面全流程 5 秒自动强退，正常完成仍提前退出；
  超时允许放弃未完成保存及终端尾部输出。
- 损坏的模型目录缓存恢复内置种子；刷新状态损坏则重建并安排下载。清除失效验证器，
  避免种子数据被错误的 304 长期保留。真实文件访问或写入错误仍上抛，并记录恢复告警。
- 会话正文同一字节只编码一次用于哈希与写盘；未变索引不重复替换，索引缺失仍重建。
  History/Context 保持分别保存。运行中回合的重写频率后来改为最多每 2 秒一次，
  回合收尾仍同步提交（2026-11-12）。
- 非 Windows 的原子 JSON 替换增加父目录 fsync，Windows 原替换语义不变。
- 模型/工具参数、引擎展示、桌面展示用增量缓冲累积，仍逐 delta 实时输出；
  已发布字符串不随后续追加、重试、显示替换而改变。
- retry 状态仅在变化时取锁更新，活动消息使用经 ID 校验的索引；delta 不再全量对账文件、
  标签和终端，仅更新工作区消息投影；深拷贝保留必要所有权隔离，移除一层冗余消息克隆、
  无订阅者的快照和一份冗余订阅者快照。
- Hook 条件在规则生命周期内预编译，push/pop 后更新；HTTP Hook 客户端继续保留。
- 模型请求体改用 bytes.Reader；远程 SSE 保留无限恢复与可取消行为，首次重连仍 1 秒，
  持续故障时指数退避并抖动，间隔封顶 30 秒，收到有效事件后复位。
- MCP stdio 保存最多 16 KiB 启动 stderr，在失败诊断中脱敏展示，保留原错误链。
- 非回环无 TLS 的服务启动增加告警（2026-11-12 起改为拒绝启动，需显式
  `--allow-insecure-listen`；密钥改为显式揭示端点并记录审计）。
- 共享按钮覆盖进入统一语义变体，保留原有紧凑尺寸、内边距和业务回调；
  Base URL/API Key 标题走本地化，Tokens 保留既有术语；链接提示读取主题与字号 token。
  共享按钮外观门禁扩展到整个桌面包。
- 删除仓内无引用的 BrowserAnnotation 别名。output 增加独立模块边界，保留历史证据，
  修复全仓 Go 工具扫描生成中文工作区失败的问题。

## 已确认策略及功能影响

用户已决定前三项保持现状；第四项选择策略 2，退出总上限为 5 秒。

| 决策 | 目前保留的行为 | 若进一步修改的实际影响 | 建议 |
|---|---|---|---|
| 1. 强制 TLS | 2026-11-12 起非回环无 TLS 拒绝启动，需 `--allow-insecure-listen`；凭据只经显式揭示端点返回 | 直接强制会使未声明的裸 HTTP 部署无法连接，因此保留显式豁免开关 | 已按上述方案实施；显式豁免用于隧道/反代部署，密钥仍只按用户动作揭示 |
| 2. 敏感文件打开 | 聊天链接可打开执行宿主的项目外文件，Markdown/网页已有不同限制 | 全面限定 CWD/项目会阻止跨项目资料与配置排障；敏感路径确认会增加一次点击；拒绝列表会彻底禁止对应文件查看 | 优先只对明确敏感配置增加打开确认，保留普通项目外文件读取；需先确定敏感范围 |
| 3. 系统凭据库 | 配置明文落盘，使用权限与原子替换保护 | 凭据可能绑定当前 OS 用户/机器，配置复制备份不能直接带走密钥；无桌面 Linux 不一定有可用 keyring | 当前先保留；引入前明确跨机器备份及无桌面部署方案 |
| 4. 强制退出时限 | 正常清理与保存，桌面全流程共用 5 秒预算；提前完成立即退出 | 超时自动结束 GCode，退出码 1，无确认；未完成保存和尾部输出可能丢失，异常强退不保证原生自动重启已完成 | 已按用户选择实施，不增加等待/强退弹窗 |

ui-5/6/7 属外观整合建议，未证明当前功能错误；既有视觉优化目标继续暂停。

5 秒计时在主窗口关闭事件（或直接开始业务关停）时、原生销毁和业务清理前启动，
只启动一次，后续退出回调
不重置计时；直到入口及其清理即将返回才解除。正常路径继续取消本机任务并尽力回收
进程；强退本身不保证异常子进程已全部回收。远程宿主任务不受客户端强退影响。
超时诊断异步尝试写运行日志和 stderr，不允许日志阻塞继续拖住退出，因此不能保证
强退诊断落盘。无桌面服务入口保持原策略。

新增验证：虚拟时钟准确检查 5 秒与重复关闭不重置、正常完成撤销计时器；
真实测试子进程阻塞且日志不可用时仍以退出码 1 结束。原生正常设置重启保存验收通过：
`output/shutdown-5s-native-complete/20261105-105234-2600549520/evidence.json`。
