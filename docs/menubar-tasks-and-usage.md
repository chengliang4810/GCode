# 菜单栏任务与用量

## 范围

参考 Cindy 的菜单栏弹出面板形态，使用 GCode 原生 Go/MyGo 重写。按用户最新要求，**不包含余额、订阅、充值、额度仪表或任何金额信息**。

设置入口为「用量统计 → 在菜单栏显示任务与用量」，默认关闭。开启后出现 GCode GC 模板图标，右侧显示今日 Token 用量（例如 1.8K Token）；点击图标打开原生圆角、毛玻璃浮层；点击外部或 Escape 收起。设置旁的「打开菜单栏面板」提供相同入口。

面板包含：

- GCode 标题、统计更新时间与手动刷新。
- 当前进行中及未读任务数量。
- 未读、进行中、今日用量三个标签；任务点击跳到真实会话，确认未读沿用现有核心行为。
- 今日 Token、轮次、工具次数及模型分布。
- 近 30 天当前宿主的 Token 总量、趋势以及完整统计页入口。
- 打开 GCode（保留当前会话、草稿）、菜单栏设置入口。

## 数据与生命周期

- 任务来自核心轻量 Sessions 投影，不读所有历史正文；排除归档和子智能体，活跃任务不重复出现在未读结果中。
- 用量复用 ApplicationUsageService.ReadApplicationUsage 和现有 appUsage 投影。打开浮层、手动刷新、浮层可见期间业务快照变化时后台读取；隐藏时不新增轮询。未知或失败状态不显示为零。
- 主窗和浮层通过同进程强类型状态交互，不引入 helper、IPC、WebView。
- 启用状态随 Settings.MenuBar 保存；关闭设置或退出应用销毁浮层与托盘，浮层失焦只隐藏以便再次打开。
- 菜单栏图标源于现有 GCode 小尺寸字标，去掉方形底色、转换为模板色，以便系统按菜单栏深浅主题着色。
- MyGo Tray/NewFlyout 提供原生能力，发布包无需包含自动化插件。

## 验证边界

组件覆盖中英文、深浅主题、标签切换、真实设置保存、任务投影及导航保留草稿。原生 E2E 使用独占核心数据目录验证设置保存、托盘锚定浮层、三个标签、真实核心统计读取和关闭设置。原生自动化通过设置旁入口打开与托盘同一浮层，不将它描述为 OS 鼠标点击菜单栏的验收。当前验证平台为 macOS；其他平台托盘行为未验收。

### 零用量空模型分组修复

本机持久统计的 8 天数据均包含空模型键，但对应 Token 全为 0，没有发现实际 Token 无模型归属。原因是用户消息和无计费活动记录仍执行 Models[ModelID] += 0，菜单栏直接遍历该 map，把空键展示成“未知模型 · 0”。

聚合现在仅为正 Token 记录建立模型分组，轮次和工具调用仍照常统计；菜单栏复用完整用量页已有的 appusage.Models，统一过滤零用量并按用量排序。未把空键冒充成当前模型，也未丢弃真实计量。
