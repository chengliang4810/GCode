# Git 历史

历史面板通过 `contracts.GitHistoryService` 按需读取真实提交，不从聊天消息推断提交，
也不把提交列表放入普通会话快照。会话存在时使用宿主会话的 CWD；没有会话时使用所选项目目录。
客户端只提交会话或项目 ID，不能指定任意宿主路径。本机强类型直连核心，远程使用认证后的
`POST /v1/git-history`，Git 命令在宿主执行。

核心复用现有安全 Git 命令入口，后台执行 `git log --all --topo-order`，最多读取 501 条、
显示 500 条；超过上限时明确提示。保留 SHA、父提交、标题、作者、作者时间和引用，
HEAD 根据 Git 引用标记定位。空仓库、非 Git 目录与执行错误分别显示。单次读取最多 15 秒。

打开历史或点击刷新会重新查询；普通对话快照不会逐次重跑 Git。切换会话取消旧请求，
并通过请求代次拒绝旧结果。历史可按标题、作者或 SHA 搜索，搜索范围是已加载的提交；
点击提交沿用现有详情弹窗，可查看 SHA、父提交、作者和日期并复制 SHA。

验证：真实临时仓库包含中文提交、分支和合并提交；覆盖空仓库、非 Git 目录、
错误路径、取消、500 条上限；面板覆盖刷新、搜索、会话切换、错误状态、中英文、
深浅主题及窄窗；远程接口覆盖宿主数据与未认证请求拒绝。组件和临时仓库测试
不代表已安装应用或真实远程设备验收。
