# 会话工具记录

工具协议名称用于模型调用；中文动作、摘要与详情由共享的会话展示投影提供。
本机与远程客户端使用相同的 `contracts.ToolCall`，桌面不解析工具协议来补做业务状态。

| 工具 | 动作 | 摘要 |
| --- | --- | --- |
| TaskOutput | 读取任务结果 | 任务描述，缺省使用命令或任务 ID |
| TaskStop | 停止任务 | 任务描述或任务 ID |
| Skill | 使用技能 | 实际调用的技能名 |
| goal_read | 读取目标 | 本次读取的目标内容 |
| ListDirectory | 列出目录 | 目录路径 |
| WebFetch | 读取网页 | 请求地址 |
| WebSearch | 搜索网页 | 查询内容 |
| Agent | 启动智能体 | 委派任务描述；成功启动后显示子智能体记录 |
| MCP 工具 | 调用工具 | 插件、服务名称与工具可读标题 |

MCP 标题按 `title`、`annotations.title`、`name` 的顺序选择。
展示名称不参与模型工具 schema 或 `tools/call`，原始工具身份保持独立。
任意 MCP 参数与输出仍可在详情中检查，不推测未知外部工具的业务语义。

已知内置工具的详情展示动作对象和实际输出；目标详情展示本次读取的目标、
状态、用量、预算、下一步与原因。目标快照独立克隆，不随之后的目标编辑变化。
读取失败保留原始错误与参数。子智能体取消请求显示“已请求停止”，
不会在进程或执行者退出前显示“已停止”。

网页搜索在最终的会话工具集合中按设置加入，避免被会话运行工具替换。
只读子智能体继续使用其受限的文件工具集。
