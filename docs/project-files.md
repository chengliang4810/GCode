# 项目登记与异步文件加载

项目登记只校验所选目录并持久化名称、路径和设备等信息。提交成功后才启动宿主拥有的
后台任务，读取 Git 元数据与文件列表；目录遍历、Git 子进程均不持有引擎状态锁。
客户端断开不取消已接受的加载，项目删除、重复刷新和宿主退出会取消相应任务。
旧任务的迟到结果不能覆盖新结果或恢复已删除的项目。

`Project.FilesState` 和 `Project.FilesError` 独立表示文件列表状态。文件加载失败不会
回滚项目登记；文件面板显示加载状态或错误，并可通过 `project.files.refresh` 重试。
项目创建错误、文件加载错误与结果保存错误写入运行日志。

Git 项目通过 Git 的忽略规则排除构建产物和缓存，支持规则中的否定及已跟踪文件语义；
没有 Git 仓库或工具时仍可浏览普通目录。文件树仍跳过 `.git`、`node_modules`、
`target` 和符号链接。文件列表保留 50000 项、30 秒及忽略清单 4 MiB 的资源边界；
达到边界时保留已得到的列表并单独报告加载未完成，不拒绝项目创建。

已打开的文件缓冲区在后台结果发布时保留。项目内链接的归属按项目与源会话目录判断，
不依赖后台文件索引是否完成；其他项目、其他 checkout 和工作目录外的文件保持只读。
尚未完成的加载在宿主重新启动后重新调度。
