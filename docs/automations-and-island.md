# 自动化与灵动岛

## 当前实现

自动化入口位于左侧栏「新建对话」下方，打开独立任务管理页；灵动岛开关位于「设置 → 灵动岛」。自动化由同一 Go 核心执行；桌面通过强类型命令直接调用核心，远程客户端经现有认证协议访问宿主。`cmd/gcode-server` 无需图形环境也会启动调度器。

自动化支持：

- 五段 Cron、IANA 时区、完成后相对间隔（60 秒至 366 天）、手动执行、仅执行一次。
- 指定项目、模型和思考强度；每次新建对话、持续使用同一对话、绑定已有普通对话。
- 新建、编辑、暂停、恢复、立即执行、确认删除；删除保留生成的对话。
- 持久化运行历史、运行状态、错误、整秒耗时，以及打开结果对话。界面在选中任务的详情中显示运行记录，核心保留全部记录。
- 同一自动化不重叠，最多同时运行三个自动化。满额或绑定会话正忙时，已到期任务保留到期状态，等待空位。
- 暂停在配置落盘后取消正在运行的自动化；编辑和删除运行中任务会要求先暂停并等待结束。
- 离线期间不补跑；重启不重放已接受的输入，运行中记录恢复为中断。若核心已保存终态，则恢复该终态。
- 执行失败保留失败记录，不自动禁用周期任务。已归档或丢失的持续会话记为失败，不悄悄替换目标。

Cron 解析复用 `github.com/robfig/cron/v3`，不自写日期匹配器。时区数据库随 Go 服务打包。配置及运行索引与核心现有索引一起提交，复用存储独占锁。

灵动岛是 MyGo 原生独立置顶窗口，默认关闭。支持：

- 屏幕顶部黑色紧凑胶囊和展开任务列表，按屏幕中心锚定，展开向下。
- 等待输入、失败、运行中、未读完成结果的优先级排序；不读取全部历史对话正文。
- 出现新的待输入或完成/失败状态时展开；完成提示约 5 秒后收起，失败提示约 12 秒后收起，手动展开不自动收起。
- 点击回到主窗口对应对话，停止运行，忽略完成卡片，以及关闭灵动岛。
- 完成结果最多展示 24 小时；已归档和已读结果不展示。忽略及打开会话会确认未读状态，后续新结果仍可提示。
- 灵动岛只统计用户自己发起的对话：子代理会话、侧聊和工作流的实例会话都不计入，
  一次工作流运行里的多个实例不会变成多条任务。
- 主窗深浅主题、浮窗固定黑色主题、共享按钮/开关及整秒时间格式。

核心现在会在执行终态保存会话未读标记和完成时间；从会话列表或灵动岛选择会话时确认已读。该标记是会话状态，不由浮窗复制执行状态。
