# 对话文件目录

文件面板以当前对话的 `Session.CWD` 为根目录。无项目对话使用核心为其分配的工作目录，
worktree 对话使用实际 checkout；没有选中项目或对话时，不汇总所有项目的文件。
当前会话与项目根目录相同时复用核心已有项目索引；其他会话目录通过
`SessionFilesService` 在宿主后台读取，本机使用强类型 Go 调用，远程客户端使用外围 HTTP 适配器。

目录首次出现时折叠，展开状态按会话保存；搜索只使用同一目录的数据。
切换会话取消旧目录读取，并以请求代数拒绝过期结果。任务完成或重新打开面板时刷新目录，
流式回复不反复扫描。文件系统扫描设 30 秒上限，复用现有项目扫描的忽略规则、符号链接规则及条目上限。

会话目录中的文件通过已有 `ReadLinkedFile` 接口打开，保留源会话归属。
内置支持 UTF-8 文本/代码、Markdown 预览以及 PNG、JPEG、GIF、WebP、BMP、TIFF、SVG 图片。
办公文档、PDF、归档、音视频、未支持的图片/字体、数据库、电子书、CAD/三维文件等交由系统默认应用；
未知扩展名仍检查实际内容，无法作为 UTF-8 文本读取的文件也走外部打开，不再当作文本错误。
本机已知外部类型直接打开原文件；远程文件先从宿主下载到私有临时目录，再由客户端默认应用打开。
外部打开不新增空白编辑标签，成功交接时清除旧读取错误；权限、缺失文件及已支持格式的损坏等实际错误仍正常报告。
本机文件右键提供“在文件夹中显示”，使用共享 Reveal 回调在文件管理器定位；
远程宿主路径不交给客户端文件管理器。
项目外文件沿用该接口的只读预览边界，不提供当前尚无对应核心命令的新建、重命名和删除入口。
项目根目录继续使用现有文件编辑与管理功能。

验证覆盖：无项目会话、不同 checkout、同名根目录隔离、目录折叠与展开、按会话保存状态、
隐藏条目、当前目录搜索、源会话文件打开、任务结束刷新，以及远程宿主目录查询。
这些自动化证据不代表系统输入法、真实供应商或完整视觉验收。
