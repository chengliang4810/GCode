# 界面语言

2026-10-29 按用户要求加入国际化：默认简体中文，英文为备选。入口是
**设置 → 通用 → 语言**，切换立即生效，保存到现有状态文件的
`settings.general.language`（`zh-CN` / `en`）。旧状态缺少此字段时使用中文。
语言变化不会修改会话内容、代码、文件名、用户命名、模型标识或服务商名称。

中文目录在 `internal/i18n/zh-CN.json`，英文源文案作为键和缺失翻译时的回退。
应用文案只在显式的界面显示位置翻译。设置路由、控件 key、选项 value、后端命令
以及权限答案仍保留原值。搜索设置可使用中文或英文标题。
`internal/i18n/view` 在根控件的局部状态里保存语言字符串，不保存 Context/Element。
MyGo 的简体中文控件目录随应用加载，原生查找栏、编辑器和菜单跟随语言切换。

`--language en` 可用于英文验收；`--language zh-CN` 可显式选择中文。
历史参考截图和两个专用原生 fixture 继续明确使用英文，不据此声称中文视觉一致。
旧交接文档“保留英文”的产品要求已由本次要求取代，历史验收记录保留原范围。

验证包含默认值、旧状态迁移、保存恢复、当前页即时切换、根控件语言隔离、格式参数、
字面文案覆盖和原有英文交互回归。Windows 原生窗口已实际切换中文 → 英文 → 中文，
最终构建的原图、辅助功能树和检查记录位于 `output/i18n-final/evidence/`
及 `output/i18n-final/validation.json`。macOS 原生显示未在本次验证。
