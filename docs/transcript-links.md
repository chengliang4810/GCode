# 正文与文件预览链接

2026-10-30，GCode 独立实现链接解析、原生交互与侧栏导航。
历史行为依据见 [RCode 调查](rcode-links-investigation.md)；未复制参考项目源码。
本轮是用户明确要求的链接接入，没有恢复已暂停的完整视觉一致性目标。

## 展示与交互

- 正文、数学混合段落、用户引用和表格中的链接共用解析和导航策略。
  文件 Markdown 预览也使用同一链接控件。
- 链接显示主题色文字，不附文件图标、箭头、灰色代码背景或常驻下划线；
  hover 显示点状下划线。显式 Markdown 标签保留作者文字。
- 已知项目文件及合法绝对文件路径的行内代码显示为可操作的文件名；
  包括未进入项目索引的会话生成文件，同名项目文件增加必要路径。
  未知相对路径及普通行内代码保持代码样式。
- hover 或键盘 focus 显示完整目的地址，文件显示来源宿主的绝对路径及行列；
  深色提示最大宽度 360、高度最多 24 行，超出后内部滚动。
- 普通点击、Enter/Space 激活；Tab 聚焦；Shift+F10 打开菜单。
  从链接开始拖动可选择文本，不触发导航；跨段落选择仍由原生选择范围管理。
- 文件菜单支持内部打开和复制路径。本机文件另有默认应用打开、显示目录；
  远程文件不显示这两个本机系统动作。
- URL 菜单支持内部打开、外部打开、复制地址以及默认内部打开的开关。
  偏好保存在 `Settings.General.OpenLinksExternally`，默认值为 false。

普通复制保留显式链接标签。完整选中自动缩短的文件标签时恢复原始路径；
部分选中时复制所见文本。完整自定义链接段落的「复制为 Markdown」保留源文，
部分选择及未登记的原生段落按所见文本处理，没有声称任意 Markdown 片段
都具备语法偏移映射。长 URL 当前保留全文并自然换行，未实现 RCode 的视觉省略映射。
数学和用户引用的特殊混排保留各自排版，使用同一链接交互入口；
跨混排换行的装饰不作为像素一致性验收。

## 归属与导航

链接回调固定绑定发出消息的会话，不能随其他面板的最后一次构建改变。
当前 workspace 只接受其 root 或后代会话的链接；切换 root 后，过期动作不再打开内容。
打开文件或网页只选择右侧页签，不切换中央会话，也不清除中央草稿。

聊天正文支持 POSIX 路径、Windows 盘符路径、file URL 和工作目录相对路径。
相对路径只属于来源会话的 CWD，不按文件存在性尝试其他 checkout。
正文拒绝 `.`/`..`、UNC、drive-relative、query 等歧义路径。
Windows 路径按自身语法处理，不依赖 UI 客户端的操作系统。

行列支持 `:12`、`:12:5`、`#L12`、`#L12C5` 和正向行范围。
范围定位首行；行列从 1 开始，列按字符计算，进入编辑器前转换为 UTF-8 字节列。
零行、零列和逆序范围无效。

`.md` / `.markdown` 大小写无关，默认 Preview。
带行号时进入 Code 并定位；预览使用当前编辑缓冲区，重复打开保留未保存内容。
预览中的相对路径基于文档目录，允许合法 `../`；文档内 heading 锚点滚动，
`mailto:` 使用系统邮件程序。预览不接受绝对文件目标，与聊天正文有意不同。
图片在原生文件页读取来源宿主管理的 resource，并使用已有图片缩放、平移控件。

`LinkedFileService.ReadLinkedFile` 是真实文件读取边界：
本机 UI 直接调用 Go 核心；远程客户端通过认证后的外围适配器让宿主读取。
相对路径使用 `os.Root` 拒绝目录穿越和符号链接逃逸。
会话所属项目内的现有文件复用文件 ID 与保存能力；其他绝对文件只读打开。
正文 UTF-8 文件限制 16 MiB，图片沿用附件尺寸及容量限制并校验格式。
链接文件读取成功后清除工作区上一次错误，避免先打开二进制文件失败、
再打开有效 UTF-8 文本时，旧编码错误仍显示在新正文上方；同一文件读取失败后重试亦适用。
读取在渲染线程外执行，来源、请求代数或 workspace 改变后丢弃过期结果。
已知项目文件读取完成后先发布包含完整 Files 的核心快照，再返回读取结果，
防止后续流式消息把客户端文件缓冲区退回旧内容。图片资源按内容哈希复用，
完整临时文件写完后才发布；图片显示结果同时校验请求代数、资源引用和版本。
快照先到或读取结果先到，都不会继续显示旧图片。同版本的只读、加载与名称
元数据仍会更新，同时保留未保存编辑及冲突基线。

模型产生的网页目标必须为显式 HTTP(S)，不接受凭据、空白/控制字符、
反斜杠和损坏的 percent escape；拒绝后不会回退到系统 opener。
只有用户地址栏输入可补全 `https://`。

## 浏览器初始页

新建 Browser 标签现在显示原生空地址页，地址栏为空并可输入。
输入合法地址或点击网页链接后才创建 WebView；空白时刷新和外部打开不可用。
原先 `OpenSurface("browser")` 固定访问 `https://go.dev`，这条默认导航已删除。

PNG/SVG 和侧栏网页加载，同时检查中央草稿及会话保持。
